# Chepian Server 0.1.1

Release type: Diagnostics checkpoint

## Added

- Modular chep architecture
- chep doctor
- System, CPU, memory, disk, network, service and security checks
- Diagnostic archive collection
- Automatic sudo elevation
- Command tests
- Server-only ISO
- Chepian boot splash

## Changed

- Improved package command routing
- Improved safety checks
- Updated Chepian identification

## Not Included

- Server profiles
- Offline bundles
- Docker/Kubernetes profiles
- Independent dependency resolver

## Known Limitations

- chep still uses apt/dpkg.
- doctor checks are advisory.
- Bootloader text branding can vary between BIOS and UEFI.
- Development project, test before production use.

## Upgrade

No supported in-place upgrade from 0.1.0 yet. Use the new ISO for testing or installation.
